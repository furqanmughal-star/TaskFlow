Questions

Windows or Android shows a security warning. Is it safe?

The installer is not signed with a paid publisher certificate, so Windows SmartScreen and Android Play Protect show a generic warning for every new app. If you received this link from the developer, you can continue: on Windows choose More info → Run anyway; on Android choose Install anyway.

Do I need an account?

No. TaskFlow works fully without one and stores tasks on your device. Create a free account inside the app (☁ button) only if you want the same tasks on your phone and laptop.

Is there an iPhone app file?

Apple does not allow installing app files from a link. Use Open TaskFlow → Share → Add to Home Screen; it then behaves like a normal app with its own icon.

How do I update?

The web version updates itself. For Windows and Android, download the newest file from this page and install it again — your tasks stay.
